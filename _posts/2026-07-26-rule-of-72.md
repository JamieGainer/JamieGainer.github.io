I was thinking about quantifying how prices have changed lately, 
and it was making me think of "the rule of 72", 
which is a rough heuristic for how long it takes to double 
your money at $p\%$ interest.  (The answer is $72 / p$).

To understand why this is true we solve for $n$ in the equation
$$
(1 + p/100)^n = 2.
$$

Taking the (natural) log of both sides, we obtain
$$
n (\log{1 + p/100}) = \log{2}.
$$

So if we take the frist term in the Taylor series for $\log{1 + x}$, 
we obtain 
$$
np/100 = \log{2},
$$
So $n = 69.31/p$.  But you'll notice that $69.31 \neq 72$.  
So the issue here is for the realistic small percentages where one might want to use
an approximation like this, the next term in the Taylor series will "correct" 
the value in the numberator to be closer to $72$.

Specifically, the next term in the Taylor series for $\log{1 + x}$ is $-x^2/2$.
So the number in the numerator is increased, versus the naive assumption, 
by about $p/2$ percent.  So we'd expect the rule of $72$ to be literally
true for $p$ of around $8\%$ or so.

We can evaluate this exactly by calculating $\log(2) / 
\log(1 + p/100)$ for various choices of $p$.  The table below shows
the exact doubling time $n$ and the corresponding value of $np$.

| Interest rate $p$ | Doubling time $n$ | $np$ |
| ---: | ---: | ---: |
| $1\%$ | 69.66 | 69.66 |
| $2\%$ | 35.00 | 70.01 |
| $3\%$ | 23.45 | 70.35 |
| $4\%$ | 17.67 | 70.69 |
| $5\%$ | 14.21 | 71.03 |
| $6\%$ | 11.90 | 71.37 |
| $7\%$ | 10.24 | 71.71 |
| $8\%$ | 9.01 | 72.05 |
| $9\%$ | 8.04 | 72.39 |
| $10\%$ | 7.27 | 72.73 |

Note that we are implicitly assuming that the $n$ above, which represents,
say, the number of years at a given annual interest rate before doubling,
is a continuous variable, though this isn't a very interesting caveat.
